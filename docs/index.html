こえきゃぷ (KoeCap) for OBS

声で話した「いまやっていること」を、OBS の画面に字幕として出す Windows 用のアプリです。

できること

  • キーワード（例:「いまやっていることは」）のあとに話した 1 文が、字幕になります。
  • キーワードで、字幕を消す・ひとつ前に戻す・OBS のホットキーを押す などの操作もできます（声のコマンド）。
  • 声の聞き取りは、このパソコンの中だけでします。声・字幕・設定をインターネットに送ることはありません。

ダウンロード（最新の版）

はじめての方 全部入りの zip 前の版から更新する方 更新の zip（0.20 以降を使っている方）

それより前の版を使っている方は、「はじめての方」の zip を使うか、Releases の説明を見てください。版ごとに変わったことと前の版の zip も Releases にあります。

入れ方

  1. zip を展開する
    できた KoeCap フォルダを好きな場所に置きます（例: ドキュメント\KoeCap）。
  2. OBS にスクリプトを足す
    OBS の「ツール」→「スクリプト」→「＋」→ KoeCap フォルダの koecap.lua を選びます。
    はじめての時は、音声モデルのダウンロードを始めます（数分。待つだけで大丈夫です）。
    このとき「アプリを再起動」は押さなくてかまいません（押すとダウンロードがやり直しになります）。
  3. OBS にドックを足す
    OBS の「ドック」→「カスタムブラウザドック」で、ドック名に こえきゃぷ、URL に http://localhost:8765/ と書いて「適用」を押します。

そのあと、ドックの「⚙」→「出力先」→「テキスト(GDI+)を追加」で字幕が出せます。くわしい使い方は zip の中の README.txt にあります。うまく動かないときは、README.txt の「7. 困ったとき」を見てください。

更新するとき: OBS を閉じてから、更新の zip の中の KoeCap フォルダの中身を、今の KoeCap フォルダに上書きでコピーします。設定は消えません。

動かすのに必要なもの

  • Windows 10 / 11（64bit）
  • OBS Studio 30 以降
  • インターネット（はじめに音声モデル 約 730 MB をダウンロードするときだけ）
  • ディスク 約 400 MB・パソコンのメモリ 8 GB 以上（ゲームを配信するときは 16 GB 以上をおすすめ。こえきゃぷは約 2 GB を使います）

Python などを別に入れる必要はありません（アプリ専用の Python が zip に入っています）。
